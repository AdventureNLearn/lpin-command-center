## I — Inference

The draft is a height-banded **Core-metro + fake state-bubble** sketch. It is not clustering Extra/More. It is not Rest opt-in. It is not an engine feature.

`searchAhj("a"|"e"|"i")` is the wrong primitive for pack counts: named search is hit-capped, vowel-biased, Rest-blind, and the result is thrown away. Filling in the empty loop would still be junk. Honest cluster counts come from a **state index of named desks** (and later, lazy Rest **after** opt-in), never from typeahead probes.

`Math.max(..., 1)` plus 56 centroids is a silent lie: every territory looks like a pack of 1. Kit language is “visible pack,” not “billboard the union.”

`STATE_SCALE_M = 250_000` would uncluster (into the 12 cores) above the seat-21 county line (80 000). Copy `ORBIT_M` as the **no-Rest / no-leaf** hard stop; use **80_000** as the inner expand band. Do not fork a second orbit constant. Raise only if FPS dies.

Engine wire is the same shape as LEG, plus the flights **camera key**. LEG does not need zoom bands (≤33 country contacts). AHJ does. A subscribe-only `if (layers.permits.on) add(permitMarks(cam.height))` without `onCamForPermits` fails the kit table on the first zoom.

Lazy Rest is a **search/card** problem first, a **pin** problem second. `PlaceDesk` has no coordinates. Kit Done (“city search still finds a Rest name if opted in”) does **not** require 14,925 Cesium entities. Pins without a sourced coordinate = **do not draw**. Search hits in the drawer do not require pins. Inventing Census lat/lon to make `permitMarks` look busy is the named P0.

First-paint stays honest today because the helper is unreachable. The failure mode after this pass is wiring the draft **as-is**: 12 orbit cores + 56 fake packs, still no Rest search, still no camera reload, still a comment that says `don't use this`.
