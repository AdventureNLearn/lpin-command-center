# Useful tool — two audiences

**Class:** public-suite WIP · not a ship  
**AOS:** orchestrator + evidence-gate + civic-intelligence + visual globe  
**Loop:** iterate → audit → forecast → execute (repeat in the 4h window)

## Everyday person

They should be able to:

1. Open the globe and talk in plain English.
2. Ask “what’s over Japan” or “who sits in Canada” (also France, and the other 33) and get a **card**, not a yank.
3. Press **Look here** if they want the map to follow. They never have to.
4. Open a legislature or building desk and see names **or** an honest empty.
5. Turn on planes / quakes / fire as public feeds, not classified theater.
6. Hear “we don’t have that pack yet” instead of a fake complete picture.

## Serious user

They should be able to:

1. Trust **delayed / sourced / hole** language.
2. Use the 33 on-disk legislatures without invented sittings.
3. Search permit catalog (Core/featured) without Rest dump or certified-fake portals.
4. Keep Grok comms open while a desk is open.
5. Never get an auto-score, auto-truth, or auto-zoom.
6. Human final call on Fly / Open desk.

## Evidence-gate on the card

| Kind | Basis | Tri-state |
|------|--------|-----------|
| 33-kit roster counts | kit `meta.json` | +1 as filed, 0 if named 0 |
| Permit portal | catalog URL | 0 unverified |
| Jobsite rows | none on disk | 0 honest hole |
| Live planes | public ADS-B | +1 as feed, not navigation |

Software does not auto-truth. Incomplete stays empty.
