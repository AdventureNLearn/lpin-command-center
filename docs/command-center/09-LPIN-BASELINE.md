# LPIN product baseline

**Decision:** D-269 · Every LPIN-class product after this sitting inherits this file.  
The Civic Command Center is the **pattern parent**. It is not a git submodule and not a forced Cesium dependency.

---

## Must inherit (all LPIN products)

1. **Integrity kernel** — tri-state where scored; Evidence / Inference / Assumption; primary records beat commentary; human final call; honest “we do not know yet.”
2. **System label** — every user-facing claim surface names its tool (Claims, Jobsite, …). Unlabeled mix is a defect.
3. **Geographic OPSEC** — no municipality names in samples, packs, or public docs. User types locality.
4. **No skill chrome** on public navigation.
5. **No PII** in demos. No secrets in git.
6. **Clean-share gate** — do not present an incomplete board as complete.
7. **Workdesk Generator** — a new grok.me / LPIN tool is a **pack** before it is a homepage.
8. **Ship law** — live route or tag or WD decision, **plus** OPSEC. Tokens ≠ ship.

## May inherit (if the product maps)

- GEV globe as homepage
- `.holo-card` Insight / Peek
- Opt-in Look here (no auto-zoom)
- Exclusive rail, civic layers default off
- 0 orbit pins unless the pack names a typed fly
- Radio as companion, not as proof

A Claims-only page with no globe is still LPIN if it keeps 1–8.

## Must not inherit

- GEV as a silent rename of LPIN (public pin says Civic Intelligence / LPIN)
- Tutor scoring
- Kept harvest restart
- IDWT door, Embassy bus, EEW, games
- Operator-internal roster on the HUD
